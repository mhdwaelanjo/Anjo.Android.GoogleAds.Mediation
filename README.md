# Anjo.Android.GoogleAds.Mediation

---------------------------------
Mediation Adapter For The Google Mobile Ads SDK for .NET Android (formerly Xamarin.Android) bindings for AndroidX library - Wael Anjo
---------------------------------

AdMob mediation is a feature that lets you serve ads to your apps from multiple sources, including the AdMob Network, third-party ad networks.
 
 ### Documentation:
Google Mobile Ads SDK (AdMob) documentation : https://developers.google.com/admob/android/mediation

- Integrate AdColony with mediation : [documentation](https://developers.google.com/admob/android/mediation/adcolony)
- Integrate AppLovin with mediation : [documentation](https://developers.google.com/admob/android/mediation/applovin)
- Integrate Chartboost with mediation : [documentation](https://developers.google.com/admob/android/mediation/chartboost)
- Integrate Meta Audience Network (previously Facebook) with mediation : [documentation](https://developers.google.com/admob/android/mediation/meta)
- Integrate IronSource with mediation : [documentation](https://developers.google.com/admob/android/mediation/ironsource)
